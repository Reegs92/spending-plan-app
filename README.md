# Continuous Spending Plan

A free, open-source spending plan app that helps you become conscious of where your money goes.

## Features

- **Income tracking** with frequency conversion (weekly, fortnightly, monthly, yearly, custom)
- **Expense management** — enter an amount in any frequency and see it converted to all others
- **Account allocation** — distribute expenses across multiple bank accounts
- **Spending awareness** — break down habits like "takeaway 3x/week @ $20" to see real costs
- **What-if scenarios** — adjust spending habits and see the impact on your budget
- **Import/Export** — save and load your plan as JSON
- **Auto-save** — data persists in your browser automatically
- **Zero dependencies** — pure HTML, CSS, and JavaScript
- **Works offline** — no server required, just open `index.html`

## Getting Started

1. Download or clone this repository
2. Open `index.html` in your browser
3. Enter your income and start adding expenses

## Privacy

All data stays on your device in browser localStorage. Nothing is sent to any server.
